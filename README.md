# 施工風險評估報告書產生工具（網頁版）

依「設計階段施工風險評估報告書產生工具 — 開發規劃書」製作的瀏覽器版本。這個版本**不用安裝任何程式**，下載後直接用瀏覽器開啟就能使用，所有檔案都只在您的電腦上處理，不會上傳。

## 開始使用

1. 下載整個資料夾（GitHub 頁面右上角 **Code → Download ZIP**，解壓縮）。
2. 用 **Chrome 或 Edge** 直接開啟資料夾中的 `index.html`（滑鼠點兩下即可）。
3. 依左側步驟操作：

| 步驟 | 做什麼 | 產出 |
|---|---|---|
| 1 母本解析 | 選擇母本 .docx，檢查章、表、圖、分節、樣式是否正確辨識 | 結構驗證報告 .xlsx |
| 2 分類與標籤確認 | 確認每段的 F 專案事實／T 通用範本／C 條件式／M 混合，以及條件標籤 | 分類確認表 .xlsx（可修改後匯入） |
| 3 專案資料 | 讀入新案的 docx／xlsx 取得建議值，填寫專案事實、確認條件標籤，勾選「已確認」 | 專案資料確認表 .xlsx |
| 4 工項規劃 | 檢視依條件標籤自動決定保留或刪除的內容，可逐筆指定 | 工項規劃表 .xlsx |
| 5 產出報告 | 產出新案報告書，並可執行「還原測試」 | 報告書 .docx、差異清單 .xlsx |
| 6 一致性檢查 | 檢查跨章節矛盾、表號引用、日期、風險值、母本殘留、錯字、待填 | 一致性檢查報告 .xlsx |

開啟產出的 Word 檔時，Word 會詢問「是否更新此文件中的欄位」，請選 **是**，目錄、表號、圖號就會自動重排。

### 重要觀念

- **母本設定**：在「3 專案資料」勾選「顯示母本設定欄」，填入每個欄位在母本中的值與實際寫法（例如「地上4層」）。產出時工具只會替換這些寫法，因此母本設定越完整，替換越準確，一致性檢查的殘留比對也越完整。
- **新案沒提供的資料**：一律標成紅字【待填：欄位名稱】，不會帶入母本的數字。
- **專案事實不算條件**：工程名稱裡有「納骨塔」、構造寫「RC造」等，不會讓該段落被當成條件式內容而刪除。
- **圖片與表格截圖**：只有圖、沒有文字的段落，以及表名下方是圖片（或只放圖片的表格）的「表格截圖」，也會分類。依圖名／表名自動初判：照片、位置圖、配置圖、地質、承載力等判為 F，產出時換成紅框【待補圖：圖x-x 名稱】，圖名保留；流程、架構、示意等判為 T，沿用原圖；出現條件關鍵字的判為 C，依標籤保留或刪除。沒有圖名或無法判斷時預設為 F。分類頁可看縮圖（emf／wmf 只顯示檔名）。圖片的確認結果也會記入記憶庫：有圖名的依名稱（不含編號）記憶；沒有圖名的依圖片檔內容記憶，同一張圖（例如機關標誌）出現在任何母本、任何位置都會沿用。圖片中的文字無法讀取，請人工確認沿用的圖沒有母本資料。
- **文字方塊與頁首頁尾**：封面等處文字方塊內的文字、各節頁首頁尾，也會替換專案事實、自動更正錯字，並納入一致性檢查（頁首頁尾不加 Word 註解）。
- **記憶庫（換母本不用重來）**：在「2 分類與標籤確認」確認或修改過的分類、標籤與工項規劃，會依「段落文字」記住。換母本或母本改版時，文字完全相同的段落自動沿用；相似的段落（預設 90% 以上）標為「推定」；沒看過的標為「新段落」。用「只看需確認的」篩選，只核對推定與新段落即可。舊版有、新版沒有的段落會另外列出，不會套到其他段落上。記憶庫可以匯出、匯入（合併）給同事共用。
- **記憶庫管理（左側「記憶庫」頁）**：記憶庫存在這台電腦的瀏覽器中（換電腦或瀏覽器請用「匯出備份 .json」，或儲存專案檔）。這一頁可以：
  - 檢視全部記憶與統計（各分類、各標籤、來源母本、衝突筆數、目前母本的涵蓋率）
  - 完整性檢查：衝突、C 類沒有標籤、有標籤但不是 C、非 C 卻指定刪除、目前母本沒有的記憶
  - 逐筆修改分類、標籤、工項規劃，或勾選多筆批次改分類、標為已解決衝突、刪除；修改立即套用到目前母本
  - 匯出 Excel 逐筆檢查（可多人分工），修改「分類／標籤／工項規劃」或在「刪除」欄填「刪除」後匯入
- **關鍵字建議**：在「規則設定」頁（或記憶庫的「關鍵字建議」按鈕）分析記憶庫，工具會找出「你標了某個條件標籤、但目前關鍵字抓不到」的段落，歸納它們共同出現的詞，建議加入關鍵字；也會找出常誤判的關鍵字，建議移除。每項都標示可多抓幾筆、會誤抓幾筆，按「加入」或「移除」才會生效；套用後重新初判，已確認的段落不受影響。
- **資料保存**：設定會自動存在這台電腦的瀏覽器中。換電腦或備份時，用上方「儲存專案檔」存成 .json，之後用「開啟專案檔」讀回。母本 .docx 不會被儲存，每次開啟需重新選擇。

## 檔案結構

```
index.html          主畫面
css/app.css         畫面樣式
js/rules.js         預設規則與欄位（可在「規則設定」頁修改）
js/docx.js          docx 解析、保留格式的文字替換、顏色標示、Word 註解
js/kb.js            分類初判、條件標籤推導、工項規劃、風險矩陣
js/memory.js        依文字內容記憶分類與標籤（換母本、改版沿用）
js/gen.js           產出報告、差異清單、還原測試比對
js/check.js         一致性檢查
js/app.js           畫面與流程
js/vendor/          JSZip 3.10.1、SheetJS 0.18.5（離線可用）
tests/              測試用模擬母本產生程式與端對端測試
```

## 開發者測試

```bash
pip install python-docx
python tests/make_sample_docx.py tests/fixtures/sample_master.docx
npm install playwright   # 或使用已安裝的 Playwright
node tests/e2e.js
python tests/make_sample_docx.py tests/fixtures/sample_master_v2.docx --v2
node tests/e2e_memory.js
node tests/unit_keywords.js
node tests/e2e_memory_page.js   # 需要 openpyxl
```

`tests/fixtures/sample_master.docx` 是依母本結構虛構的小檔，不含真實母本內容。
